# Public-source follow-up — 2026-09-11

This search supplements, rather than silently replaces, the supplied `agent.md`.

- **NVIDIA/OCP geometry:** [NVIDIA's contribution announcement](https://developer.nvidia.com/blog/?p=90182) describes enhanced blind-mate manifolds and floating connections. It does not provide a tray pressure–flow curve in the retrieved material.
- **OCP reference collateral:** The [ORv3 blind-mate manifold specification](https://www.opencompute.org/documents/open-rack-v3-blind-mate-manifold-specification-rev-1-0-review-april05-2024-pdf), pages 8–9, describes interfaces and simplified STEP collateral, expressly distinguishing it from a complete implemented manifold. This does not identify exact GB200 hydraulic dimensions. Generic ORv3 dimensions were not substituted for NVIDIA/OEM hardware.
- **Connectors:** The [OCP Danfoss UQDB listing](https://www.opencompute.org/products/412/danfoss-hansen-universal-quick-disconnect-blind-mate-uqdb) identifies a family of blind-mate connectors. No evidence retrieved establishes a specific connector as the GB200 rack's installed part. Generic connector performance therefore cannot be treated as the actual tray QDC curve.
- **Dell:** Search results include [IR7000/M7725 technical material](https://www.delltechnologies.com/asset/en-ca/products/servers/technical-support/poweredge-m7725-technical-guide.pdf) for another implementation. Shared rack family naming does not justify transferring its dimensions or connector choices to the GB200 reference case.
- **CDU control:** The search-index excerpt of Vertiv's [CDU121 operation and maintenance guide](https://www.vertiv.com/490001/globalassets/shared/80278-cdu-121-operation-maintenance-reva-10-25-locked.pdf) describes flow and differential-pressure control. Full PDF retrieval failed in this session. The model retains the supplied nominal point and explicitly assumed shutoff; no full pump curve was recovered or invented.
- **PG25:** [Dow's product page](https://www.dow.com/en-us/pdp.dowfrost-lc-25-heat-transfer-fluid.497419z.html) identifies LC25 as a PG25 fluid for technology cooling loops. The supplied 40/50°C anchors remain the numeric authority for this run; extensions remain estimates.
- **Water:** The [IAPWS liquid-water release](https://www.iapws.org/relguide/LiquidWater.pdf) provides authoritative temperature-dependent property context. The checked-in table is generated using IAPWS97 at 0.1 MPa through the pinned iapws implementation.

This search is not proof that manufacturer data do not exist. The model's remaining unknowns are the exact hardware identity, hydraulic curves, dimensions and qualified operating maps for the target installation. Replacement hooks are implemented so such data can be incorporated later.
